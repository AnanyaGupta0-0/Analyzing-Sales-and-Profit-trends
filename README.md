# 📊 Sales and Profit Analysis Dashboard

An interactive and insightful Excel dashboard project created as part of my Data Science Minor at Lovely Professional University. This dashboard provides comprehensive business intelligence by visualizing sales and profit data across multiple dimensions — time, geography, product categories, and customer segments.

## 🧠 Objective
To design a comprehensive sales and profit analysis dashboard using Microsoft Excel, enabling businesses to:
- Track performance over time
- Identify top-performing regions, products, and customers
- Discover areas for strategic improvement
- Support data-driven decision-making

## 📌 Key Features

- **Profit Gained Over Time**: Line chart showing trends from 2014 to 2017 across categories.
- **Sales by States**: Interactive choropleth map visualizing regional performance.
- **Sales by Category**: Funnel chart for sales by main product categories.
- **Top 5 Customers Making Profit**: Pie chart highlighting the top contributors.
- **Monthly Sales Trend**: Area chart showing monthly fluctuations.
- **Customer Count Over Years**: Horizontal bar chart tracking acquisition trends.
- **Most & Least Profitable Products**: Highlight cards for instant insights.
- **Category vs Sub-Category Performance**: Treemap to compare sales depth.
- **Slicers for Interactivity**: Filter dashboard views by Year and Category.
- **Pivot Tables**: Backend tables supporting all visualizations for flexible data slicing.


## 🧹 Data Preprocessing Steps
- Removed duplicates and anomalies (e.g., negative profits)
- Standardized date formats for time-series analysis
- Categorized data into Year, State, Category, Sub-Category
- Created new features (e.g., profit margin)
- Aggregated metrics (monthly/yearly sales, customer count)

## 🔍 Insights Discovered
- **Technology** was the most profitable category
- **California** led in total sales
- **Canon imageCLASS 2200** was the top product by profit
- **Cubify CubeX 3D Printer** resulted in significant loss
- Consistent **growth in customer acquisition** year-over-year

## 📈 Tools Used
- Microsoft Excel
  - Pivot Tables
  - Slicers
  - Charts (Line, Bar, Pie, Funnel, Map, Treemap)
